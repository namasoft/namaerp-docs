# ملف المعالج (Wizard File) — سجل معالج الإعداد

عادةً ما تُجهَّز المنشأة الجديدة عبر **معالج الإعداد**: استبيان على خطوات يسأل كيف تعمل الشركة —
عملتها، وفروعها، والمستندات التي تستخدمها، وهل تُنشأ الأصول الثابتة من المشتريات، وغير ذلك — ثم
يُنشئ الدفاتر والتوجيهات والمجموعات والإعدادات المناسبة دفعة واحدة. و**Wizard File** هو السجل الذي
يحمل تشغيلًا واحدًا لهذا الاستبيان: كل إجابة تُحفظ عليه، فيمكن إغلاق المعالج وإعادة فتحه وتعديله
وتطبيقه من جديد لاحقًا.

أغلب المنشآت لها Wizard File واحد. في قاعدة البيانات التجريبية هو السجل ذو الكود `demo`.

## الشاشة

| الحقل | ما هو |
|---|---|
| الكود والأسماء | كما في أي ملف رئيسي. |
| *(الإجابات)* | حقل نصي كبير يحمل الإجابات المحفوظة. يملؤه المعالج — لا تعدّله يدويًا. |
| جدول **الحسابات** | أسطر من **الحساب** و**Wizard Classification**. كل سطر يربط حسابًا بالدور الذي يستخدمه المعالج فيه. |

حفظ السجل يكتب **Wizard Classification** لكل حساب على الحساب نفسه، وحذف السطر يمسحه من ذلك الحساب.
لا يتكرر الحساب في الجدول.

## تشغيل المعالج

احفظ السجل ثم اضغط **Go To Wizard**. يُفتح المعالج في تبويب جديد بخطوة لكل مجال — **الأساسيات**،
**الحسابات**، **الاصناف و إعداداتها**، **المخازن**، **المشتريات**، **المبيعات**، **الأصول**، **الموارد
البشرية**، **التصنيع**، **نقاط البيع** وغيرها. لا تظهر إلا المجالات التي يغطيها ترخيصك.

- **التالي** / **السابق** للتنقل بين الخطوات.
- **حفظ** يخزّن الإجابات على Wizard File دون أن يُنشئ شيئًا.
- **تطبيق المعالج** يمر على الخطوات كلها بالترتيب، ويفحص إجابات كل خطوة، ويُنشئ ما تصفه. يتوقف عند
  أول خطوة تفشل ويعرض الخطأ.
- **تطبيق مختار** يفعل الشيء نفسه لكنه يتخطى كل خطوة أُشِّر فيها **عدم تطبيق** (في مجموعة **تطبيق
  إختياري** داخل تلك الخطوة). استخدمه لإعادة تشغيل مجال واحد — مثلًا بعد إضافة موديول — دون المساس
  بغيره. ولا أثر لـ **عدم تطبيق** مع **تطبيق المعالج** العادي.

الأسئلة الجديدة التي تُضاف في الإصدارات اللاحقة تظهر عند حفظ Wizard File في المرة التالية، وتبقى
الإجابات السابقة كما هي.

## صفحات ذات صلة

- التوجيهات التي ينشئها المعالج قد تترك أسطر القيد فارغة — راجعها قبل حفظ أول مستند، كما تشرح [توجيهات مستندات الشحن](/ar/modules/freight/freight-document-terms) لموديول الشحن.
- المجموعات التي ينشئها لكل نوع ملف رئيسي: [المجموعات الرئيسية](/ar/platform/documents-and-records/master-groups).
- سؤال الأصول الثابتة الذي يطرحه: [الأصول الثابتة — البداية](/ar/modules/fixedassets/fixedassets-getting-started).
