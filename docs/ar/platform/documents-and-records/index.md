# المستندات والسجلات

كل شاشة في نظام نما تحفظ أحد أمرين: **مستندًا** — حدثًا له تاريخ مثل فاتورة أو سند — أو **ملفًا رئيسيًا** تشير إليه المستندات مثل عميل أو صنف. تشرح هذه الصفحات الآليات المشتركة بينهما: كيف ينتقل المستند من المسودة إلى الاعتماد ثم يعود، ومن أين يأخذ رقمه، وكيف تُكوَّد الملفات الرئيسية وتُجمَّع، وما يمكنك إرفاقه بالسجل، ولماذا يرفض النظام أحيانًا حفظ سجل أو حذفه.
