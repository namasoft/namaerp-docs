# أدوات يومية

الأشياء الصغيرة التي يستعملها كل مستخدم يوميًا أيًّا كانت وحدته: الأزرار التي تشترك فيها كل الشاشات، واختصارات لوحة المفاتيح، وخانة البحث في الشريط العلوي، ونصوص المساعدة على الحقول، والثيمات، والملحوظات وبنود الأجندة على السجلات، والقوالب التي تملأ السجل الجديد، وإيقاف استعمال سجل دون حذفه.
