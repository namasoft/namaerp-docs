# التنبيهات

عندما يحدث أمر مهم في النظام — فاتورة جديدة، أو طلب موافقة، أو خطأ في المعالجة — ينبغي أن يصل الخبر إلى الشخص المعني دون أن يتذكر أحد إبلاغه. يراقب نظام التنبيهات في نما أحداث العمل ويرسل الرسائل تلقائيًا عبر تنبيهات داخل النظام والبريد الإلكتروني والرسائل القصيرة وWhatsApp. تعرّف على كيفية عمل المحرّك والنماذج، واضبط مزودي SMS وWhatsApp، وراجع الأسئلة الشائعة عندما لا تصل رسالة إلى وجهتها المتوقعة.
