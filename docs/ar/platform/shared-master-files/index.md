# الملفات الرئيسية المشتركة

بعض الملفات الرئيسية لا تخص وحدة بعينها — بل تقرؤها كل الوحدات. وهي المحددات التي يُصنَّف تحتها كل سجل، والعملاء والموردون وجهات الصلة الذين تتعامل معهم، والعملات التي تتعامل بها، والجوانب المحاسبية الجاهزة التي تُسجِّل التوجيهات مبالغها عليها. تُعدّها مرة واحدة فتعمل الحسابات والمخازن والموارد البشرية وغيرها من السجلات نفسها.
