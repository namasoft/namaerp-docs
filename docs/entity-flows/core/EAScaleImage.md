# EAScaleImage

## Overview

An entity flow line with four parameters about image size. To reduce the main image of a master file (an item picture, for example) use [EAScaleMasterFileImage](/entity-flows/core/EAScaleMasterFileImage), which holds the scaling rules.

## Parameters

The flow line shows these titles above its parameters:

**Parameter 1:** Scaled Width

**Parameter 2:** Scaled Height

**Parameter 3:** Attachment Field ID

**Parameter 4:** Allowed Extensions, eg: jpg,png,bmp

**Module:** core

**Full Class Name:** `com.namasoft.infor.domainbase.util.actions.EAScaleImage`
