# The Menu

The tree down the side of the screen is not fixed. It is a record you can edit, and most
installations do — dropping the modules the company does not use, renaming folders to match what
people actually call them, and putting the three screens everyone lives in where they can be
reached in one click.

There is one thing to know before you start: the menu that ships with the system is rebuilt from
scratch by several ordinary administrative actions, so changes typed into it do not survive. The
supported route is a Menu Update, and it takes about the same amount of work.
