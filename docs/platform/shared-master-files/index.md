# Shared Master Files

A handful of master files belong to no single module — every module reads them. They are the dimensions every record is filed under, the customers, suppliers and other parties you deal with, the currencies you deal in, and the reusable account sides that document terms record their amounts on. Set them up once and accounting, supply chain, HR and the rest all work from the same records.
